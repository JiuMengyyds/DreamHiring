# DreamHiring 页面原型

这是招募系统 V1.0 的高保真交互原型，用于在正式开发前确认信息架构、视觉方向和三角色业务闭环。

## 预览

直接打开 `index.html`，或在项目根目录启动任意静态文件服务器后访问 `prototype/`。

右上角 `DEMO` 菜单可切换三种身份：

- 求职者：职位检索、匹配度、投递、简历、消息。
- 企业 HR：职位管理、候选人流程、企业资料。
- 平台管理员：职位审核、用户与企业治理、分类公告。

左侧「行业招聘洞察 / 全局数据看板」进入独立数据大屏。

`previews/` 目录内附主要页面的 1440px 视觉快照，便于评审时快速浏览。

## 演示路径

1. 求职者在职位广场筛选杭州职位，进入职位详情并投递。
2. 在「我的投递」查看状态，在简历页编辑技能标签。
3. 切换企业视角，在候选人看板处理「林知夏」的投递状态。
4. 切回求职者查看消息与投递进展的联动。
5. 切换管理员视角，审核职位并查看全局数据看板。

## 说明

- 原型使用本地内存数据，不请求后端，刷新页面后恢复初始状态。
- 页面以 1440px 桌面端为主要验收尺寸，同时支持平板与移动端布局。
- 正式实现技术仍按架构方案使用 Vue 3 + Vite + Element Plus + ECharts 5。
